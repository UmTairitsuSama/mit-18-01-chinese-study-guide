## 如何使用

建议从第 0 章开始顺序学习：先阅读概念和例题，再独立完成练习，最后展开答案核对步骤，并用章末自测清单检查掌握情况。复习章节可用于单元检测，期末章节用于综合训练。

在线阅读界面支持：

- 按章阅读、目录跳转和上一章／下一章导航。
- 折叠练习答案、插图放大、目录与正文搜索。
- 字号、字体与深浅色设置。
- 书签、错题、自测、高亮与学习记录备份。

学习记录保存在当前浏览器本机，不会自动在设备间同步。更换浏览器或清理浏览器数据前，请先在“记录”面板导出 JSON 备份。
